# WiFi Screen Remote (Android + Chrome)

اپ اندرویدی Kotlin برای نمایش زنده صفحه گوشی در Chrome و ارسال لمس/حرکت از مرورگر به گوشی، روی شبکه محلی Wi‑Fi.

> این ZIP شامل سورس پروژه و GitHub Actions است؛ APK از قبل داخل آن کامپایل نشده است. بعد از Push پروژه به GitHub، Workflow فایل `ScreenRemote.apk` را می‌سازد و آن را به‌صورت Artifact فشرده‌شده تحویل می‌دهد.

## ویژگی‌ها

- انتقال تصویر زنده با WebRTC به‌جای ارسال اسکرین‌شات‌های متوالی.
- وضوح ضبط تا حداکثر ضلع ۱۹۲۰ پیکسل، نرخ هدف ۳۰ فریم بر ثانیه و سقف bitrate حدود ۸ مگابیت بر ثانیه؛ مقدار واقعی به سخت‌افزار گوشی و کیفیت شبکه بستگی دارد.
- صفحه کنترل داخل خود گوشی میزبانی می‌شود؛ سرور سیگنالینگ به سرویس ابری احتیاج ندارد.
- کنترل لمس، کشیدن، Back، Home و Recent از Chrome با AccessibilityService.
- بدون رمز عبور؛ فقط یک اتصال WebRTC در هر لحظه.
- Android 8.0 به بالا (API 26+).

## ساخت APK با GitHub Actions

۱. فایل ZIP پروژه را Extract کنید.
۲. محتوای پوشه را در یک GitHub repository جدید قرار دهید و به شاخه `main` Push کنید.
۳. از بخش **Actions** اجرای workflow با نام **Build Android APK** را باز کنید. با هر Push به `main` یا `master` نیز خودکار اجرا می‌شود.
۴. پس از موفقیت، در بخش **Artifacts** مورد `ScreenRemote-APK-ZIP` را دانلود کنید. GitHub آن را به‌شکل فایل ZIP بسته‌بندی می‌کند.
۵. ZIP دانلودشده را باز کنید؛ فایل `ScreenRemote.apk` داخل آن است.

Workflow از JDK 17، Android SDK 35، Android Gradle Plugin 8.10.1، Kotlin 2.2.20 و Gradle 8.13 استفاده می‌کند. نیازی به کلید امضای انتشار نیست؛ خروجی فعلی Debug APK است و برای نصب و تست مناسب است. برای انتشار عمومی در Google Play باید نسخه Release امضاشده و الزامات سیاست Accessibility بررسی شود.

## روش استفاده

۱. گوشی و کامپیوتر را به یک شبکه Wi‑Fi وصل کنید. شبکه نباید Client/AP Isolation داشته باشد.
۲. APK را نصب و اجرا کنید.
۳. دکمه **فعال‌سازی کنترل لمس** را بزنید و سرویس «کنترل از راه دور صفحه» را در تنظیمات Accessibility روشن کنید. برای پخش تصویر، این مرحله لازم نیست؛ فقط برای کنترل از مرورگر لازم است.
۴. **شروع اشتراک‌گذاری** را بزنید و مجوز سیستمی ضبط صفحه را تأیید کنید.
۵. آدرس نمایش‌داده‌شده در برنامه، شبیه `http://192.168.1.20:8765/`، را در Chrome کامپیوتر باز کنید.
۶. در صفحه مرورگر **اتصال به گوشی** را بزنید. روی تصویر کلیک/لمس کنید یا درگ کنید. دکمه‌های Back، Home و Recent نیز در نوار بالای صفحه هستند.
۷. برای پایان کار در اپ گوشی **توقف اشتراک‌گذاری** را بزنید.

## نکات مهم و محدودیت‌ها

- Android برای هر نشست ضبط صفحه، اجازه واضح و سیستمی کاربر را لازم دارد. برنامه نمی‌تواند این مجوز را بی‌صدا دور بزند.
- کنترل لمس از طریق Accessibility انجام می‌شود و باید کاربر آن را دستی فعال کند. برخی پوسته‌های سازندگان گوشی ممکن است رفتار متفاوتی داشته باشند.
- «بدون رمز» یعنی هر دستگاهی در همان شبکه محلی که آدرس را بداند می‌تواند صفحه را ببیند و فرمان بدهد. از شبکه عمومی، هتل، دانشگاه یا Wi‑Fi مهمان استفاده نکنید. آدرس را با افراد دیگر به اشتراک نگذارید.
- صفحه وب و فرمان‌های کنترل از HTTP محلی استفاده می‌کنند. خود رسانه WebRTC از رمزنگاری DTLS-SRTP بهره می‌برد، اما سیگنالینگ/فرمان‌های HTTP روی LAN رمزنگاری جداگانه ندارند.
- برنامه تأخیر صفر را تضمین نمی‌کند. نتیجه به چیپ رمزگذار سخت‌افزاری، دمای دستگاه، قدرت Wi‑Fi، تداخل رادیویی و مرورگر وابسته است. برای بهترین نتیجه از Wi‑Fi 5GHz یا 6GHz و فاصله نزدیک به روتر استفاده کنید.
- بعضی برنامه‌ها (مانند صفحه‌های دارای DRM، بانکی یا دارای `FLAG_SECURE`) ممکن است تصویر سیاه یا محدودشده نشان دهند؛ این محدودیت امنیتی اندروید است.
- صدا منتقل نمی‌شود و فعلاً فقط یک مرورگر می‌تواند به گوشی متصل شود.
- STUN عمومی فقط برای کمک به مذاکره شبکه است؛ ترافیک ویدئو از مسیر WebRTC منتقل می‌شود. در برخی روترها یا شبکه‌های ایزوله ممکن است اتصال برقرار نشود.
